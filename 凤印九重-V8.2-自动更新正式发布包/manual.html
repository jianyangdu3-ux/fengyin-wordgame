凤印九重

游戏说明书 · 宫斗背词

1游戏简介

《凤印九重》是一款宫斗背词游戏。你扮演一名寒门秀女，从选秀入宫到母仪天下，历经九重位份晋升。

5491 个考研核心词汇藏在每一幕剧情、每一场考校、每一次斗法之中。记不住词，就活不过这一章。

核心设计：所有玩法（剧情、考校、斗法、抉择、查案、情缘）全部绑定考词——不是看小说，也不是刷题软件，而是用单词当武器在深宫博弈。

2位份体系 · 九重晋升

从秀女到皇后共九级，每晋一级获赐一枚凤印，首页角色立绘随位份自动切换：

4考校系统 · 限时答题

选择题（英→中）

  • 给出英文单词，选中文释义（4 选 1）
  • 15 秒倒计时，超时判错，最后 3 秒计时条变红
  • 答对 +15 圣宠，连击 2 次以上 ×2 倍率
  • 答错 -5 圣宠 -3 心力，自动收入错词本
  • 答题前角色会出一句台词（姑姑/华妃/皇后风格各异）

飞花令（拼写题）

  • 给出中文释义 + 首字母 + 字母数，你需要拼写出完整英文单词
  • 20 秒限时，答对 +20 圣宠
  • 答错显示正确答案，自动收入错词本
全对通关 +30 圣宠，金色「考校全通」印章。通过后进入下一环节（斗法/抉择/晋升）。
考校入场消耗 5 心力，心力不足会被拦下，提示去词库温书恢复。

5斗法系统 · 回合制博弈

斗法是战斗化测验——把每道题包装成一回合出招，答对=攻击，答错=被反击。

回合流程

  • 敌方先出招：随机「三十六计」招式名（指鹿为马、笑里藏刀、暗渡陈仓…）
  • 你12 秒限时拆招：看英文选中文，倒计时条最后 3 秒变红
  • 答对：对方血条闪红 + 飘伤害数字 + 屏幕震动
  • 答错/超时：被反击 -25 血，对方嘲讽
  • 一方血量归零即结束

连击技名系统

连续答对触发技名升级，伤害递增：

2 连巧言令色伤害 28
3 连妙语连珠伤害 38
4 连+凤鸣九天伤害 50
胜利奖励：+40 圣宠，若以「凤鸣九天」绝杀额外 +30 圣宠。失败：-15 心力，可重新斗法。斗法入场消耗 10 心力。

6心力系统 · 体力与风险

心力是你在这深宫的精力值，上限 100，每天跨天自动回满。顶栏右侧实时显示。

-5考校入场
-10斗法入场
-3答错一题
-15斗法败北
  • 心力不足时无法入场，提示「先去温书恢复」
  • 点击提示跳转词库，浏览/复习词条 +30 心力
  • 心力 =0 时所有考校/斗法入口锁定
心力让答错有真实代价——不能无限重试，每次失误都在消耗你的精力，逼迫你认真对待每一题。

7复习系统 · 错词本与收藏

词库三 Tab

  • 全部词：5491 词库，搜索浏览，点开看释义+听发音
  • ⭐ 收藏：手动星标的词，随时温习
  • ❌ 错词：答题/斗法/情缘暗号答错的词自动收录，带错次统计

收藏方式

  • 剧情中点击红色高亮词 → 弹出释义面板 → 底部「⭐ 收藏」
  • 词库列表点击任意词 → 释义面板 → 「⭐ 收藏」
  • 收藏过的词在列表中显示金色 ★ 标记

一键复习

  • 在收藏/错词 Tab 点「📖 复习」→ 进入复习考校（限时出招那套）
  • 复习入场消耗 5 心力
  • 答对的词自动从错词本销账（错次清零移除）
  • 错词本全清空显示「错词本已清空 ✨」
考校/斗法失败后，结果面板有「📖 先去错词本复习」按钮，直接跳过去温习再回来重考。

11存档管理

本地存档

进度自动保存在浏览器 localStorage，无需注册。包含位份、圣宠、心力、剧情进度、错词本、收藏、抉择记录、情缘结局。

⚠ 换设备 / 换浏览器 / 清缓存 进度会丢失，请用导出/导入或云同步迁移。

导出 / 导入存档

  • 藏录页 → 宫册面板 → 「🔐 导出存档」→ 生成密文（GDSAVE1 开头）
  • 可「复制密文」或「下载文件」存成 txt
  • 新设备打开游戏 → 「📥 导入存档」→ 粘贴密文 → 确认导入
  • 密文含全部进度，无账号信息，可放心分享

云端同步（推荐）

用你的 GitHub 私有仓库当云端，免密 8 位存档码多设备接管。全自动：每次存档后 2.5 秒自动上传，打开游戏自动拉取，关页面瞬间兜底再传一次。按时间戳仲裁：云端新→接管恢复，本地新→推上去。

⚠ 首次开通需要注册 GitHub（免费）+ 约 5 分钟，以后一劳永逸。

📖 开通教程（跟着点就行）

第 1 步 · 建私有仓库

  1. 打开 github.com/new（没账号先注册）
  2. Repository name 填 fengyin-saves（名字随意）
  3. 可见性选 Private（私有），千万别选 Public
  4. 其余不用动，点 Create repository 完成

第 2 步 · 建 Token（只给这一个仓库开权限）

  1. 打开 Fine-grained tokens 页面（先登录）
  2. Token name 随意填；Expiration 选 90 天（到期再建一次即可）或 No expiration
  3. Repository access 选 Only select repositories → 勾选第 1 步建的仓库
  4. Permissions → Repository permissions → Contents → 选 Read and write
  5. 点最下方 Generate token → 立刻复制（只显示这一次！）

第 3 步 · 游戏内配置

  1. 藏录页 → 「☁️ 云端配置」→ 填 用户名 / 仓库名 / Token 三项 → 点「保存配置」
  2. 提示"配置已保存"，并显示你的 8 位「存档码」即成功
  3. 之后每次存档自动上传，无需再操作

📱 换设备接着玩

  1. 旧设备：打开云端配置，记下「存档码」（如 A3K9XQ2P）
  2. 新设备：打开游戏 → 云端配置 → 填同一套三项配置 + 输入旧存档码 → 保存
  3. 自动拉回最新进度，无缝续玩 ✓
存档码是这份存档的"暗号"，填同一个码就是同一份存档。抄到备忘录，别弄丢。

❓ 常见问题

  • Token 安全吗？ 它只开这一个仓库的 Contents 读写权限，碰不到你其他仓库，泄露了也伤不到别处。
  • Token 没复制就关页了？ 重新生成一个，游戏里换上新的保存即可，旧的可以删。
  • 存档码忘了？ 随时打开云端配置弹层就能看到。
  • 两台设备同时玩？ 以时间最近的为准，打开游戏自动比对弹窗提示。
  • 不想同步了？ 云端配置里清空三项保存即可断开，本地进度不受影响。
  • 有版本历史吗？ 有。云端存档在 Git 仓库里，误操作可回滚到任意历史版本。

13实用小贴士

  • 连击是核心：连续答对伤害翻倍，尽量别断连
  • 错词本要清：答错的词会积累，定期去复习考校清空
  • 心力别浪费：心力不足就温书，别硬撑答错浪费
  • 每日任务必做：+30 圣宠是稳定收入
  • 语音功能：点单词旁的 🔊 可听发音，加深记忆
  • 剧情词可查：红色虚线下划线的词都能点开看释义
  • 存档要备份：定期导出或开云同步，防丢档
