每步怎么点？照着做就行
第 1 步 · 建私有仓库（github.com/new）
① Repository name 填 fengyin-saves（名字随意）
② 可见性选 Private（私有），千万别选 Public
③ 其余不用动，点 Create repository 完成
第 2 步 · 建 Token（只给这一个仓库开权限）
① 打开上面「去建 Token」链接，用 GitHub 账号登录
② Token name 随意填；Expiration 选 90 天（到期可再建）或 No expiration
③ Repository access 选 Only select repositories → 勾选刚建的仓库
④ Permissions → Repository permissions → Contents → 选 Read and write
⑤ 点最下方 Generate token → 立刻复制（只显示这一次！）
第 3 步 · 回来粘贴保存
把 用户名 / 仓库名 / Token 填进上方三个框 → 点「保存配置」→ 看到"配置已保存"即成功
📱 换手机 / 换电脑怎么接着玩？
旧设备：打开这个配置弹层，记下上方「存档码」（如 A3K9XQ2P）
新设备：打开游戏 → 云端配置 → 填同样的三项配置 + 输入旧存档码 → 保存 → 自动拉回进度 ✓
存档码相当于你这份存档的"暗号"，两设备填同一个码 + 同一套 GitHub 配置，就是同一份存档。
❓ 常见问题
Token 安全吗？它只是"开这一个仓库"的钥匙，只勾了 Contents 读写，碰不到你其他仓库和账号。
Token 没复制就关了页面？去 GitHub 重新生成一个，游戏里换上新的保存即可。
存档码忘了？随时打开这个弹层就能看到，建议抄到备忘录。
两台设备同时玩？以时间最近的存档为准，打开游戏会自动比对并弹窗提示，放心点。
不想同步了？清空三项配置保存即可断开，本地进度不受影响。
